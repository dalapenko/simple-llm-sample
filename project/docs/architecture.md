# Архитектура LLM Chat CLI

## Обзор

LLM Chat CLI — это интерактивный CLI-инструмент для диалога с языковыми моделями,
построенный на базе фреймворка Koog (Kotlin AI framework). Поддерживает облачные
провайдеры (OpenRouter) и локальные модели (Ollama).

## Модульная структура

```
simple-llm-sample/
├── cli-app/          — основное приложение (REPL, команды, UI)
├── indexer/          — индексирование документов (RAG pipeline)
├── mcp-server-git/   — MCP-сервер с git-инструментами
├── mcp-server-search/     — MCP-сервер: веб-поиск DuckDuckGo
├── mcp-server-scheduler/  — MCP-сервер: планировщик задач
├── mcp-server-save-file/  — MCP-сервер: запись файлов
├── mcp-server-summarize/  — MCP-сервер: суммаризация
└── mcp-server-pipeline/   — MCP-сервер: цепочки запросов
```

## Ключевые компоненты

### ConversationManager
Оркестратор взаимодействия с LLM. Собирает системный промпт из нескольких слоёв:
1. Инварианты — жёсткие архитектурные ограничения (максимальный приоритет)
2. Профиль пользователя — стиль общения
3. Контекстная стратегия — история диалога
4. Состояние задачи — FSM текущей задачи
5. MCP блок — список доступных инструментов

### Контекстные стратегии
| Стратегия        | Описание                                       |
|------------------|------------------------------------------------|
| `sliding-window` | Скользящее окно последних N сообщений          |
| `sticky-facts`   | Фиксированные факты + скользящее окно          |
| `layered`        | Трёхуровневая память (кратко/рабочая/долгосрочная) |
| `branching`      | Параллельные ветки диалога с чекпоинтами       |

### RAG Pipeline (Retrieval-Augmented Generation)
Три уровня сложности:
- **basic** — embed запрос → поиск в базе → добавить в промпт
- **advanced** — переписывание запроса (HyDE) + фильтрация + реранкинг
- **conversational** — advanced + история диалога + отслеживание состояния задачи

Хранилище векторов: SQLite с Base64-кодированными float-массивами.
Стратегии разбивки: структурная (по заголовкам/функциям) и фиксированная (по токенам).

### MCP Integration
Протокол: JSON-RPC 2.0 поверх stdio.
Серверы запускаются как подпроцессы, инструменты доступны агенту автоматически.
Одновременно можно подключить несколько серверов — реестры инструментов объединяются.

### Developer Assistant Mode
Режим ассистента разработчика комбинирует:
- RAG с документацией проекта (README, project/docs/, схемы API)
- MCP Git сервер (текущая ветка, статус, diff, история коммитов)
- Умная команда `/help` — обзор проекта через LLM вместо статичного текста
