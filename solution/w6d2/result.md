**_примечание:_** _w6d1 и w6d2 одно и тоже т.к. в первый день уже реализовано задание второго дня_

---

## 1. Зачем это нужно

До этого момента чат мог работать только через OpenRouter — облачный сервис, который пересылает запросы к платным моделям вроде GPT-4o или Mistral. Это удобно, но требует интернета, API-ключа и денег за каждый запрос.

Иногда это не подходит:
- **Конфиденциальность** — если нужно спросить о чём-то личном или корпоративном, данные не должны уходить на чужие сервера.
- **Оффлайн-работа** — нет интернета, но хочется пользоваться AI-ассистентом.
- **Эксперименты** — можно запускать любые открытые модели без ограничений, пробовать разные варианты.
- **Стоимость** — локальные модели работают бесплатно, только нужен компьютер помощнее.

Теперь чат поддерживает **Ollama** — бесплатный инструмент, который позволяет запускать LLM-модели прямо на вашем Mac, Linux или Windows.

## 2. Как использовать

### Установить Ollama

```bash
# macOS
brew install ollama

# или скачать с сайта ollama.com
```

### Скачать модель

```bash
ollama pull llama3.2        # ~2 GB, быстрая
ollama pull mistral         # ~4 GB, хорошее качество
ollama pull phi4            # ~9 GB, мощная
ollama pull qwen2.5:7b      # ~4 GB, многоязычная
```

### Запустить сервер Ollama

```bash
ollama serve
# сервер слушает на http://localhost:11434
```

### Запустить чат с локальной моделью

```bash
# Базовый запуск (llama3.2 по умолчанию)
./gradlew :cli-app:run --console=plain --args="--provider ollama"

# Выбрать другую модель
./gradlew :cli-app:run --console=plain --args="--provider ollama --local-model mistral"

# Указать свой URL (например, Ollama на другом компьютере в сети)
./gradlew :cli-app:run --console=plain \
  --args="--provider ollama --local-model llama3.2 --local-url http://192.168.1.10:11434"

# API-ключ OpenRouter НЕ нужен
```

## 3. Важные детали

- **API-ключ необязателен**: при `--provider ollama` переменная `OPENROUTER_API_KEY` не нужна.
- **RAG и /index недоступны** с локальным провайдером — эти функции используют OpenRouter для создания эмбеддингов. При попытке включить их появится понятное сообщение об ошибке.
- **MCP-инструменты работают** — внешние сервера (поиск, планировщик, файлы) подключаются так же.
- **Все стратегии памяти работают** — sliding-window, sticky-facts, branching, layered.
